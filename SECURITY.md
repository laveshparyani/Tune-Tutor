# Security Policy

## Supported Versions

This is a front-end demo/portfolio project. Only the latest version on the
`main` branch is maintained.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue, please **do not open a public issue**.
Instead, report it privately using GitHub's
[private vulnerability reporting](https://github.com/laveshparyani/Tune-Tutor/security/advisories/new),
or contact the maintainer through their [GitHub profile](https://github.com/laveshparyani).

Please include:
- A description of the issue and its potential impact
- Steps to reproduce
- Any relevant screenshots or logs

You can expect an acknowledgement within a reasonable time frame. Thank you for
helping keep this project safe.
